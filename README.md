# Irish Rental Price Prediction Using Machine Learning

## Project Overview

This project analyzes rental housing data from Ireland and applies machine learning techniques to predict rental prices.

The project was completed as part of the MSc Data Mining and Machine Learning module.

## Dataset

- Irish rental listings (2020–2025)
- More than 50,000 records

## Features Used

- Number of Bedrooms
- Year

Target Variable:
- Rental Price

## Machine Learning Models

- Linear Regression
- Decision Tree Regression
- Random Forest Regression

## Additional Analysis

- Exploratory Data Analysis (EDA)
- Feature Importance Analysis
- K-Means Clustering

## Evaluation Metrics

- Mean Absolute Error (MAE)
- R² Score

## Results

Random Forest achieved the best performance among the tested models.
